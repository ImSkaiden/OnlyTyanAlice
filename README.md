# 📻 OnlyTyanAlice

> **Универсальная гибридная платформа для всех Яндекс Станций:** прозрачный WebSocket-мост (Quasar Bridge), интеграция с LLM (OnlyTyan), нативная биометрия голосов Яндекса и Spotify Connect (Soloist).

---

## ⚡ Быстрая установка в 1 команду (для любой Яндекс Станции)

Подключитесь к колонке через **SSH** (или **ADB**) и запустите:

```bash
curl -sSL https://raw.githubusercontent.com/ImSkaiden/OnlyTyanAlice/main/install.sh | sh
```

Скрипт автоматически:
1. 🔍 **Определит модель колонки** по Device Tree и звуковой карте.
2. 🔓 **Смонтирует файловую систему в rw** и найдет `quasar.cfg`.
3. ⚙️ **Переключит `uniProxyUrl`** на ваш приватный мост `ws://195.62.49.84:8090/uni.ws`.
4. 🎵 **Сконфигурирует параметры аудио** (включая ALSA `plughw:0,0` для Мини 1).
5. 🛡 **Включит защиту от автообновлений Яндекса (OTA lock)**.
6. 🛠 **Установит утилиту управления `tyan`** в систему.
7. 🔄 **Перезапустит службы** — колонка сразу готова к работе!

## 🛠 Управление колонкой (CLI `tyan`)

После установки на колонке доступна команда `tyan`:

```bash
tyan status          # Полная диагностика: модель, сеть, статус Quasar и Spotify
tyan test            # Проверка сети, звука и связи с мостом
tyan say "Привет!"   # Озвучить фразу через динамик
tyan volume 7        # Установить громкость (1..10)
tyan restart         # Перезапуск служб Quasar / maind
tyan logs maind      # Просмотр логов в реальном времени
```

## 🔒 Безопасность и многопользовательский режим
* Колонка управляется через вашего Telegram-бота OnlyTyan.
* Поддерживается распознавание голосов по биометрии (`/station_voices`).
* Владелец может безопасно выдавать доступ друзьям через `/station_grant` и отзывать через `/station_revoke`.
