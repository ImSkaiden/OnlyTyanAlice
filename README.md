# 📻 OnlyTyanAlice

> **Полноценная гибридная платформа для Яндекс Станций:** прозрачный WebSocket-мост (Quasar Bridge), интеграция с LLM (OnlyTyan), нативная биометрия и Spotify Connect (Soloist ARM64).

---

## ⚡ Быстрая установка на любую Яндекс Станцию

Подключитесь к колонке через **SSH** или **ADB** и запустите одну команду:

```bash
curl -sSL https://raw.githubusercontent.com/ImSkaiden/OnlyTyanAlice/main/install.sh | sh
```

### Поддерживаемые устройства:
* **Яндекс Станция Мини 2 с часами** (`station-mini2-clock`) — LED-матрица часов и погоды работает нативно.
* **Яндекс Станция Мини 2** (`station-mini2`) — сенсорные кнопки `+` / `-`, звук 10 Вт.
* **Яндекс Станция Мини 1** (`station-mini`) — жестовый ToF датчик, звук 3 Вт.
* **Яндекс Станция Лайт 1 & 2** (`yandexmicro`, `plum`).
* **Яндекс Станция Миди / Станция 2** (`cucumber`, `station-midi`).

## 🌟 Как это работает

```
                 ┌──────────────────────────────────────────────────┐
                 │                  Яндекс Станция                  │
                 │   (Мини 1, Мини 2, Лайт, Миди на Linux ARM64)    │
                 └─────────────────────────┬────────────────────────┘
                                           │ wss://ot.imskaiden.xyz/uni.ws
                                           ▼
                 ┌──────────────────────────────────────────────────┐
                 │            OnlyTyanAlice Quasar Bridge           │
                 │          (Selective Binary AAPI Proxy)           │
                 └─────────────┬──────────────────────┬─────────────┘
                               │                      │
                  [Биометрия, Музыка, Погода]   [Вопросы, Общение, Чат]
                               │                      │
                               ▼                      ▼
                 ┌──────────────────────────┐   ┌───────────────────────────┐
                 │  Yandex Uniproxy Cloud   │   │  OnlyTyan AI Engine       │
                 │  (Официальные сервисы    │   │  (LLM Персона, Память,    │
                 │   Яндекса, Музыка, TTS)  │   │   Умный Дом, Telegram)    │
                 └──────────────────────────┘   └───────────────────────────┘
```

1. **Безопасный SSL (WSS)**: Колонка подключается к защищенному шлюзу `wss://ot.imskaiden.xyz/uni.ws` с TLS 1.3.
2. **Умный роутинг**:
   * Разговоры, шутки, диалоги $\rightarrow$ в **OnlyTyan LLM**.
   * Музыка, таймеры, погода, системные действия $\rightarrow$ в **Яндекс**.
3. **Автоматический обход при знакомстве голосом (Enrollment Lock)**:
   * При фразах «*давай познакомимся*» или добавлении нового пользователя бридж на 4 минуты отключает перехват реплик и отдает 100% диалога Яндексу, чтобы калибровка голоса прошла без помех.
4. **Spotify Connect (Soloist ARM64)**:
   * Официальный движок Spotify Soloist с нативным голосовым поиском треков и альбомов.

## 📂 Структура репозитория

* [`install.sh`](install.sh) — Универсальный установщик для Яндекс Станций с автоопределением модели и блокировкой OTA Яндекса.
* [`uninstall.sh`](uninstall.sh) — Скрипт отката к заводскому Яндексу.
* [`GUIDE_FOR_FRIEND.md`](GUIDE_FOR_FRIEND.md) — Пошаговый гайд простым языком для подключения Станции Мини 2.
* [`client/`](client/) — Исходники демона колонки (`glagol_daemon.go`) и скриптов автозапуска.
* [`server/`](server/) — Исходный код Go Quasar Bridge (WebSocket proxy, Protobuf AAPI роутер, классификатор).

---

## 🛠️ Запуск сервера Quasar Bridge

```bash
cd server
go build -o bin/quasar-bridge ./cmd/quasar-bridge
./bin/quasar-bridge -config config.json
```
